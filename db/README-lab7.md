# ЛР7: пользователи и администратор

Для существующей базы ЛР6 сначала сделайте резервную копию. Затем примените
`migrate-lab7-users.sql` к базе `agromarket` **один раз** от имени пользователя
с правами создания таблиц и изменения `orders`. Миграция выполняется в
транзакции, добавляет таблицу `users` и необязательное поле `orders.user_id`.
Товары и заявки не удаляются.

Пример запуска на Ubuntu VMware (пароль вводится интерактивно, не в команде):

```bash
PGPASSWORD= psql -X -v ON_ERROR_STOP=1 -h 192.168.174.10 -p 5432 \
  -U agromarket_user -d agromarket -f migrate-lab7-users.sql
```

Перед запуском скопируйте SQL-файл на VM и перейдите в каталог с ним.
При необходимости используйте `psql` от роли PostgreSQL, которой выданы
нужные права. `PGPASSWORD=` в примере убирает пароль из переменной окружения;
`psql` запросит его через терминал.

После миграции запустите из каталога backend `npm run db:admin`. Команда берёт
`ADMIN_EMAIL` и `ADMIN_PASSWORD` только из локального `.env`, хэширует пароль
с cost 10 и создаёт администратора. Повторный запуск не создаёт дубль и не
меняет пароль существующего администратора. Если email уже принадлежит обычному
пользователю, команда завершается ошибкой и не повышает его роль.

Для новой пустой базы порядок такой: `npm run db:init`, затем
`npm run db:admin`. Миграцию в этом случае не применяют: актуальный
`schema.sql` уже содержит таблицу и поле. Никогда не запускайте `db:init`
для существующей базы ЛР6.
